1) 取得正確的下載連結（raw）

你現在檔案在 repo 裡的路徑是（從你連結看）：
老船幫幫忙/pve_guest_agetn/qga-bundle.tar.gz

raw 下載連結格式是：

https://raw.githubusercontent.com/<owner>/<repo>/<branch>/<path>


所以你的 tar.gz 會是（放在 code block 方便你直接複製）：

https://raw.githubusercontent.com/yokoko168/REXFAETOOL/main/%E8%80%81%E8%88%B9%E5%B9%AB%E5%B9%AB%E5%BF%99/pve_guest_agetn/qga-bundle.tar.gz


同理，install-guest.sh、install-pve.sh 如果也在同目錄，就用同一種 raw 格式。
